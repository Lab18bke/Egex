# Egex is a Tool that aims to simplify Regex.
*Egex stands for Easy Regex.*

You can build a Regex from the left Section of the Web Interface. 
Can select flags: g, i, m, s and u.

There's a lot of regex rules possible incl. starting with, whitespaces, any digit, word characters, either / or, raw snippet and what not.

You also get a small explaination on what does the regex rule you made in 2 clicks does. 

*Notes*: Dup stands for Duplicate, it duplicates the rule while Del deletes the rule. 
There's 3 Presets: Email, URL, YYYY-MM-DD. 

All combinations of regex are shareable by sharing the link in your address bar. Every combination of rules has a different URL. 

Supports exports to Python, JS and Java too.
